Advanced setup / use a different OAuth project

The standard app is ready for Google sign-in. These settings are only needed to use your own Google Cloud project or recover backups created with a different project.

  1. Open Google Cloud and create or select a project for Simple Khata. Enable Google Drive API.
  2. Open Google Auth Platform. Complete Branding with the app name and your email. Choose External audience and publish In production to allow Google accounts beyond a test-user list.
  3. Under Data Access, add https://www.googleapis.com/auth/drive.appdata. This permission is limited to this app's backup storage.
  4. Under Clients, create an OAuth client with application type Desktop app, then download its JSON credentials file.
  5. Import that file below, click Connect Google Drive, and sign in through your browser. Then click Back Up to Drive Now for your first upload.

External apps in Testing may require reconnection after seven days. For ongoing personal use, review Google's publishing requirements and switch to Production when ready. Keep the same Google Cloud project and client when setting up a replacement computer so it can access your backups.

Backups are stored in Simple Khata's private app storage in Drive and listed here, rather than in My Drive. Older cloud copies are retained. Disconnecting keeps uploaded backups. Restore replaces current records after creating a local safety copy.
